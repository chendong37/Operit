# 01 权限能力档位

## 原状

Operit 同时支持普通 Android 权限、无障碍、Shizuku 和 Root。首台测试机不保证已经 Root，因此团队版不能以 Root 为前提。

## 修改意图

- 建立统一的能力注册表，权限来源只负责声明当前已经授权并可用的能力。
- 每个工具声明所需能力；授权状态不满足时不向 Agent 暴露执行入口，并向用户解释缺少的权限。
- 权限档位由用户明确选择，应用不在执行中静默切换权限来源。

## 档位

### 基础档位

- Android 运行时权限
- 用户主动开启的无障碍服务
- 文件选择器和应用可访问目录
- 对话、记忆、文档生成与允许范围内的界面操作

### Shizuku 增强档位

- 基础档位全部能力
- 用户主动连接的 Shizuku 服务
- 仅开放经过能力检查的系统与包管理工具

### Root 处理原则

- 首版不配置 Root，不引导解锁 Bootloader、刷机或安装 Root 管理器。
- 已经 Root 的个人测试设备也不得把 Root 设为团队全局默认能力。
- 如未来确需支持，应另立安全评审、工具白名单、逐次确认和撤权验收，不并入本次基线。

## 预期结果

同一 APK 可在不同团队手机上使用。缺少 Shizuku 或 Root 不影响基础档位；Shizuku 不可用时，相应增强工具应明确显示不可用原因。
