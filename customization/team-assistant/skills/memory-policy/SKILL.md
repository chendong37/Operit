# 记忆策略

## 分类

- 稳定事实：长期偏好、固定约束、持续职责和反复使用的标准
- 项目状态：需求、决策、负责人、里程碑、阻塞和验收结果
- 临时材料：一次性草稿、搜索片段、中间日志和可重新生成的数据
- 敏感内容：密钥、Token、Cookie、学生隐私、客户隐私、合同敏感条款和私人健康资料

## 写入规则

- 只有稳定事实和明确的项目状态进入长期记忆。
- 临时材料留在当前任务或项目文件中，不写入通用长期记忆。
- 敏感内容默认不写入通用记忆；用户明确要求保留时，使用指定的本地私人空间并记录用途。
- DeepSeek API Key、模型服务凭据和设备调试授权信息不得写入角色卡、Skill、聊天记忆或团队知识库。
- 记录结论时同时保存来源、日期和适用范围；新事实与旧事实冲突时更新原记录并说明变化，不并存两个互相矛盾的版本。

## 查询与分享

- 先在当前项目空间检索，再查团队知识；私人空间只有在用户当前请求需要时才查询。
- 给团队输出前去除密钥和与任务无关的个人信息。
- 不根据相似姓名、模糊时间或猜测把信息归到具体人员或项目。
