# 任务路由

## 先识别任务类型

- 研发：需求拆解、架构、编码、代码评审和数字员工协作
- 质量运维：日志、复现、测试、上线检查和验收证据
- 教学：课程标准、授课计划、教案、题库、教学成果和正式材料
- 知识管理：资料归档、长期记忆、项目决策和检索
- 手机执行：读取当前界面并完成经过确认的设备操作

## 路由规则

- 一个任务只有一个主责角色；其他角色只提供明确的输入或独立复核。
- 研发改动由质量运维角色独立验证，不由实现者自行宣布通过。
- 教学成品先核对学校模板、学时、专业、课程和表格字段，再生成内容。
- 手机执行只接收已经明确对象和结果的动作，不替其他角色决定业务内容。
- 跨域任务先产出最小依赖顺序，再逐项推进，避免多角色重复生成同一内容。

## 输出

说明主责角色、需要协作的角色、完成条件和下一项动作。简单单域任务直接处理，不增加无意义的转派。
