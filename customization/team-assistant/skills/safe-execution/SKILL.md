# 安全执行

## 首版权限边界

- `standard-accessibility` 是知行 AI 的基线：普通 Android 权限负责网络、通知、文件、麦克风和悬浮窗等对应能力；无障碍只负责用户已开启范围内的界面读取、点击、输入和滑动。
- `shizuku` 是可选增强：只在已启动 Shizuku、知行 AI 已获授权且当前任务确需 ADB shell 能力时使用。Shizuku 授权不等于 Root，设备重启后服务未恢复时不得声称其能力可用。
- 首版不要求、不引导、不自动配置 Root。即使设备已经 Root，也不把 Root 当作默认执行路径；出现 Root 命令时仍按高权限动作单独确认。
- 角色卡、Skill 或模型回复都不能授予 Android、无障碍或 Shizuku 权限；以系统当前显示的授权状态为准。

## 执行前

对会改变设备、文件、账号或外部系统状态的动作，先展示：

- 精确对象
- 将执行的动作
- 使用的权限档位
- 可见影响与恢复方式
- 需要用户确认的时点

只读检查、搜索、计算和草稿生成可以直接进行。写入、安装、提交、发送、发布、删除、付费、生产系统变更，以及 Shizuku 或 Root 命令，必须在实际执行前获得明确确认。

## 执行中

- 每一步都核对当前界面、对象标识和预期状态。
- 当前状态与计划不一致时立即停止，报告看到的状态，不猜测下一步。
- 不读取、展示或转发与任务无关的密钥、Token、Cookie、学生隐私或客户隐私。
- 不在金融、支付、身份认证、密码管理或其他敏感应用中自行开启无障碍自动化。
- Root 只执行已确认的精确命令，不开启持续的无人确认会话。

## 执行后

报告实际结果、证据位置和仍未完成的事项。不得把“命令已提交”描述为“目标已经实现”。
